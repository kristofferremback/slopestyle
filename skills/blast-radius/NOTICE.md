# Provenance

This skill is adapted from Lauren Tan's pstack [`blast-radius`](https://github.com/cursor/plugins/tree/main/pstack/skills/blast-radius), reviewed from Cursor's official plugin repository at commit `60c641e4fad674784b30abcf9f8915dea39df38d`.

Slopestyle keeps the proof ladder and beyond-the-diff investigation, removes pstack's `arena` dependency, lets `review` own adversarial scaling, and allows the safety argument to rest on one or a few load-bearing facts.
