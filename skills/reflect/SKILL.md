# Reflect

Mine the active transcript and resulting artifacts for evidenced durable lessons. Apply nothing without Kris's approval.

1. Scope the active run and locate its transcript without searching unrelated workspaces or private conversations.
2. Identify corrections, dead ends, repeated friction, useful shortcuts, and workflows that generalized.
3. Scale fresh independent review to the run. Do not always spawn a fixed panel.
4. Verify every lesson against transcript actions and resulting artifacts.
5. Route each finding to the narrowest strong owner: static enforcement, existing skill, repository guidance, global guidance, backlog, or drop.
6. Reject one-offs and preferences already represented correctly. Prefer improving an existing skill over creating another.
7. Present accepted, rejected, and backlogged findings with evidence and exact proposed edits.
8. Wait for explicit approval before editing guidance or skills.

Never auto-file external work or dump a lesson into `AGENTS.md`. After approved edits, run the owning repository's checks and report what changed.
